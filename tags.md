Dans MCreator, la fenêtre « Elements Tag » (ou Tags d’éléments) sert généralement à regrouper plusieurs éléments Minecraft sous une même étiquette (tag), afin de pouvoir les traiter ensemble dans ton mod.

Un tag permet de désigner un groupe d’éléments plutôt que de devoir sélectionner chaque élément individuellement.

Par exemple, tu peux créer un tag qui regroupe plusieurs minerais, plusieurs blocs ou plusieurs objets, puis utiliser ce tag dans une procédure ou une recette.

## tags

| Type                           | def                             |
| ------------------------------ | ------------------------------- |
| `blocks`                       | blocs                           |
| `items`                        | objets                          |
| `functions`                    | fonctions Minecraft             |
| `painting_variants`            | variantes de peintures          |
| `damage_types`                 | types de dégâts                 |
| `enchantments`                 | enchantements                   |
| `entities`                     | entités                         |
| `biome`                        | Biomes                          |
| `game_event`                   | Événements du jeu               |
| `structure`                    | Structures de génération        |
| `entities_variant`             | varientes d'entité (exemple cat)|
| `banner_pattern`               | Motifs de bannières             |
| `world_preset`                 | Préréglages de monde            |
| `Potion`                       | Potions, selon la version       |
| `Dialog`                       | Dialogues, selon la version     |
| `fluid`                        | Fluides                         |
| `entity_type`                  | Types d'entités                 |

namespace : Minecraft, modid, forge, neoforge, fabric
